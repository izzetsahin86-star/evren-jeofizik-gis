# Yönetici Koordinat Ayarı

Yönetici panelindeki Ayarlar ekranında gizli giriş için kullanılan üç UTM 37S koordinatı değiştirilebilir.

- Giriş sırası sabit: Nokta 2 → Nokta 1 → Nokta 3
- Tolerans: 18 metre
- Noktalar birbirinden en az 36 metre uzakta olmalıdır
- Ayarlar Vercel Private Blob üzerinde saklanır
- Kaydetme sonrası yeni koordinatlar aynı oturumda hemen aktif olur
- Kayıt alanına erişilemezse uygulama son bilinen veya varsayılan koordinatlarla çalışmaya devam eder
