# Evren Jeofizik GIS

Evren Jeofizik için mobil ve masaüstü uyumlu saha koordinat, poligon ve DES planlama uygulaması.

## Özellikler

- Sokak, uydu ve topografik harita katmanları
- Haritadan veya UTM / Lat-Lon / DMS / DDM biçimlerinden nokta ekleme
- Birden fazla poligon, sürüklenebilir köşe noktaları ve otomatik yakınlaştırma
- Alan, çevre, merkez, kenar uzunluğu, azimut, mesafe ve Δ East / Δ North hesapları
- Poligon içinde ayarlanabilir aralıkla DES grid noktaları üretme
- KML, KMZ, GeoJSON ve CSV içe/dışa aktarma
- PDF saha raporu ve tarayıcıda yerel proje kaydı

## Yerel geliştirme

```bash
npm install
npm run dev
```

Üretim derlemesi:

```bash
npm run build
```
